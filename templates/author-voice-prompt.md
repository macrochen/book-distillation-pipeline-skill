# 作者原声提取 Prompt

## 使用方法

将此Prompt与书籍PDF一起发送给AI，提取作者的语音特征。

## Prompt

```markdown
请从书中专门摘录以下内容，用于后续人格/语气校准：

1. **口头禅**：作者反复使用的短语（≥10个，按频率排序）
2. **反问句式**：作者挑战读者时常用的问句结构（≥8个）
3. **比喻习惯**：作者解释抽象概念时偏好的类比（≥8个）
4. **否定句式**：作者反对某种观点时的典型表达（≥8个）
5. **数据引用习惯**：精确到小数 vs 约数（≥5个样本）
6. **回答模式**：作者回答不同类型问题的结构模式（≥5种类型，每种≥2个原文示例）
   - 回应质疑/反对时的典型模式
   - 回应困惑/迷茫时的典型模式
   - 回应情绪化问题时的典型模式
   - 回应事实性问题时的典型模式
   - 回应"该不该做X"类决策问题时的典型模式
7. **推理风格**：作者论证和推理的典型方式（≥5个示例）
   - 习惯用类比论证？数据论证？案例论证？反问引导？
   - 推理链条的典型结构
8. **标志性论证结构**：作者最独特的 3-5 种论证方式，附完整原文示例

## 输出格式

| 类型 | 原文摘录 | 出现位置（章节/页码） | 建议用途 |
|------|---------|---------------------|---------|
| 口头禅 | "..." | 第X章 | 身份定义/开场白 |
| 反问句式 | "..." | 第X章 | 标志性提问 |
| 比喻习惯 | "..." | 第X章 | 概念解释 |
| 否定句式 | "..." | 第X章 | 反模式禁令 |
| 数据引用 | "..." | 第X章 | 证据支撑 |

## 质量门

1. 抽查至少5处，用搜索核实原文存在
2. 口头禅/反问句/比喻/否定句每类 ≥8 个，不足则返回补充
3. 回答模式必须覆盖 ≥5 种问题类型
4. 每个原文摘录必须保留完整上下文（前后各1句），不能断章取义

## 提取数量要求

每种类型至少提取 10-15 个样本（比原来的 3-5 个翻倍），确保覆盖：
- 高频出现的（反复使用3次以上）
- 有代表性的（体现作者独特风格的）
- 可迁移的（能在AI回复中自然使用的）
- 典型场景的（覆盖不同问题类型的回应）
- 独特的（只有这个作者才有的表达方式）
```
